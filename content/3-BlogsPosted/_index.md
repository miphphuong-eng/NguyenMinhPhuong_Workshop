### [Blog 1 - Building a CI/CD Pipeline on AWS: Integrating DevSecOps Before Production Deployment](3.1-Blog1/)

This blog explains how to build a CI/CD Pipeline on AWS with DevSecOps integration to improve application security before Production deployment. It introduces the main AWS services involved, describes the security testing stages including SCA, SAST, DAST, and IAST, and highlights how automated security checks, monitoring, and manual approval help identify vulnerabilities early and ensure safer software releases.

### [Blog 2 - Amazon S3: A Storage and Data Security Solution on AWS](3.2-Blog2/)

This blog introduces Amazon S3, an object storage service provided by AWS. It explores the basic concepts of Buckets, Objects, and Object Keys, along with the eight S3 Storage Classes and their common use cases. The blog also covers important features such as Versioning, Lifecycle Rules, Encryption, and Block Public Access, as well as how Amazon S3 can support data storage and management in Data & Machine Learning architectures.

### [Blog 3 - Amazon EventBridge Scheduler: A Small but Powerful Service for AWS Projects](3.3-Blog3/)

This blog introduces Amazon EventBridge Scheduler, a serverless scheduling service that allows applications to automatically trigger AWS services at specific times or recurring intervals. It explores One-time, Rate-based, and Cron-based schedules, along with useful features such as Retry Policy, Dead-letter Queue (DLQ), Flexible Time Window, and time zone support. The blog also demonstrates how to use EventBridge Scheduler to automatically invoke an AWS Lambda Function every 30 minutes, helping reduce server management and simplify automation in AWS projects.
