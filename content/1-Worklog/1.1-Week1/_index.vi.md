# NHẬT KÝ THỰC TẬP TUẦN 1

## 1. Mục tiêu Tuần 1

* Làm quen với chương trình First Cloud Journey (FCAJ).
* Tìm hiểu các quy định, yêu cầu và lộ trình học tập của FCAJ.
* Học các khái niệm cơ bản về Cloud Computing và Amazon Web Services (AWS).
* Tìm hiểu các nhóm dịch vụ AWS chính:

  * Compute
  * Storage
  * Networking
  * Database

* Tạo và bảo mật tài khoản AWS, đồng thời tìm hiểu các chính sách của AWS Free Tier.
* Học cách sử dụng AWS Management Console và AWS Command Line Interface (CLI).
* Tìm hiểu các khái niệm về Amazon EC2 và thực hiện các bài thực hành EC2 cơ bản.
* Tìm hiểu về chương trình AWS Free Tier 2025 và **$200 AWS Credit**.
* Thực hành các dịch vụ AWS thông qua các bài tập thực tế, bao gồm:

  * Amazon EC2
  * Amazon Bedrock
  * AWS Budgets
  * AWS Lambda
  * Amazon RDS

* Học cách giám sát tài nguyên AWS, kiểm soát chi phí và xóa các tài nguyên không sử dụng.
* Thành lập nhóm và chuẩn bị cho các dự án AWS trong tương lai.

# 3. Kết quả đạt được trong Tuần 1

* Nắm được kiến thức cơ bản về **Cloud Computing** và các nhóm dịch vụ AWS chính:

  * Compute
  * Storage
  * Networking
  * Database

* Làm quen với chương trình **First Cloud Journey (FCAJ)**, các thành viên FCAJ và các quy định của chương trình thực tập.
* Đã tạo và bảo mật thành công tài khoản AWS, đồng thời làm quen với **Multi-Factor Authentication (MFA)** và các cài đặt liên quan đến thanh toán.
* Làm quen với **AWS Management Console** và học cách tìm kiếm, truy cập các dịch vụ AWS quan trọng.
* Đã cài đặt và cấu hình **AWS CLI** trên máy tính cá nhân.
* Thực hành các lệnh AWS CLI cơ bản, bao gồm:

  * `aws --version`
  * `aws configure`
  * `aws configure list`
  * `aws sts get-caller-identity`
  * `aws ec2 describe-regions`

* Tìm hiểu các thành phần cơ bản của **Amazon EC2**, bao gồm:

  * AMI
  * Instance Types
  * EBS
  * Security Groups
  * Key Pairs
  * Elastic IP

* Thực hành khởi chạy EC2 instance, kết nối thông qua **SSH**, tạo và gắn EBS volume, kiểm tra volume và terminate instance sau khi hoàn thành bài lab.
* Tìm hiểu chương trình **AWS Free Tier 2025** và cơ chế **$200 AWS Credit** dành cho các tài khoản đủ điều kiện được tạo sau ngày 15/07/2025.
* Tìm hiểu hai tùy chọn tài khoản AWS Free Tier:

  * Free Account Plan
  * Paid Account Plan

* Học cách nhận và sử dụng AWS Credits thông qua các bài thực hành.
* Hoàn thành **AWS Free Tier EC2 Task**, bao gồm tạo instance, cấu hình AMI, cấu hình Key Pair, cấu hình Security Group, khởi chạy instance, kiểm tra và dọn dẹp tài nguyên.
* Khám phá **Amazon Bedrock Playground** và tìm hiểu cách làm việc với Foundation Models cho các thử nghiệm AI/ML.
* Học cách lựa chọn Foundation Model, cung cấp thông tin Use Case, tạo prompt và chạy prompt bằng Amazon Bedrock.
* Tìm hiểu cách tạo **AWS Support Case** khi quyền truy cập vào Anthropic Claude Model yêu cầu cấp phép bổ sung.
* Thực hành cấu hình **AWS Budgets** để theo dõi chi phí AWS và thiết lập thông báo qua email.
* Thực hành tạo **Serverless Web Application bằng AWS Lambda** và Lambda HTTP Blueprint.
* Tìm hiểu quy trình cơ bản để tạo, kiểm tra và xóa Lambda Function.
* Thực hành tạo **Managed Relational Database bằng Amazon RDS** và tìm hiểu về **Aurora PostgreSQL Compatible**.
* Hiểu tầm quan trọng của việc dọn dẹp tài nguyên AWS sau khi hoàn thành các bài thực hành để tránh sử dụng tài nguyên và phát sinh chi phí không cần thiết.
* Cải thiện hiểu biết về theo dõi chi phí AWS, quản lý Budget và sử dụng Free Tier Credits.
* Thành lập nhóm gồm **4 thành viên** và chuẩn bị cho việc phát triển các dự án AWS trong tương lai.
