## Week 1 Achievements:

### General Knowledge & Setup
* Gained basic knowledge of **Cloud Computing** and major AWS service groups (Compute, Storage, Networking, Database).
* Became familiar with the **First Cloud Journey (FCAJ)** program, FCAJ members, and internship regulations.
* Successfully created and secured an AWS account, configured **Multi-Factor Authentication (MFA)** and billing settings.
* Installed and configured **AWS CLI** on personal computer and practiced commands:
  * `aws --version`
  * `aws configure`
  * `aws configure list`
  * `aws sts get-caller-identity`
  * `aws ec2 describe-regions`

### Hands-on Practice
* Learned core components of **Amazon EC2** (AMI, Instance Types, EBS, Security Groups, Key Pairs, Elastic IP).
* Practiced launching EC2 instances, SSH connection, EBS volume attachment, and resource cleanup.
* Studied **AWS Free Tier 2025** and **$200 AWS Credit** mechanism for accounts created after 15/07/2025.
* Explored **Amazon Bedrock Playground**, tested Foundation Models, created prompts, and submitted AWS Support Cases.
* Configured **AWS Budgets** with email alerts to control cloud costs.
* Developed a Serverless Web App using **AWS Lambda** (HTTP Blueprint) and created a managed relational database with **Amazon RDS** (Aurora PostgreSQL Compatible).
* Formed a team of **4 members** to prepare for future AWS projects.

## Overall Learning Outcomes:

* Built a foundational understanding of AWS Cloud Computing by combining theory with hands-on practice.
* Mastered core operations on AWS Management Console and AWS CLI.
* Acquired practical experience with EC2, EBS, Lambda, RDS, Bedrock, and AWS Budgets.
* Developed skills in cloud cost control, resource monitoring, and automated cleanup to optimize costs.
