# WEEK 1 INTERNSHIP WORKLOG

## 1. Week 1 Objectives

* Introduction  to the First Cloud Journey (FCAJ) program.
* Understand FCAJ regulations, requirements, and learning roadmap.
* Learn the basic concepts of Cloud Computing and Amazon Web Services (AWS).
* Understand the major AWS service groups:

  * Compute
  * Storage
  * Networking
  * Database
* Create and secure an AWS account and understand AWS Free Tier policies.
* Learn how to use the AWS Management Console and AWS Command Line Interface (CLI).
* Understand Amazon EC2 concepts and perform basic EC2 hands-on exercises.
* Learn about the AWS Free Tier 2025 program and the **$200 AWS Credit**.
* Practice AWS services through hands-on tasks, including:

  * Amazon EC2
  * Amazon Bedrock
  * AWS Budgets
  * AWS Lambda
  * Amazon RDS
* Learn how to monitor AWS resources, control costs, and clean up unused resources.
* Form a team and prepare for future AWS projects.

# 3. Week 1 Achievements

* Gained basic knowledge of **Cloud Computing** and the major AWS service groups:

  * Compute
  * Storage
  * Networking
  * Database
* Became familiar with the **First Cloud Journey (FCAJ)** program, FCAJ members, and internship regulations.
* Successfully created and secured an AWS account and became familiar with **Multi-Factor Authentication (MFA)** and billing-related settings.
* Became familiar with the **AWS Management Console** and learned how to search for and access important AWS services.
* Installed and configured the **AWS CLI** on the personal computer.
* Practiced basic AWS CLI commands, including:

  * `aws --version`
  * `aws configure`
  * `aws configure list`
  * `aws sts get-caller-identity`
  * `aws ec2 describe-regions`
* Learned the basic components of **Amazon EC2**, including:

  * AMI
  * Instance Types
  * EBS
  * Security Groups
  * Key Pairs
  * Elastic IP
* Practiced launching an EC2 instance, connecting through **SSH**, creating and attaching an EBS volume, checking the volume, and terminating the instance after completing the lab.
* Learned about the **AWS Free Tier 2025** program and the **$200 AWS Credit** mechanism for eligible accounts created after 15/07/2025.
* Learned about the two AWS Free Tier account options:

  * Free Account Plan
  * Paid Account Plan
* Learned how to receive and use AWS Credits through practical tasks.
* Completed the **AWS Free Tier EC2 Task**, including instance creation, AMI configuration, Key Pair configuration, Security Group configuration, instance launch, verification, and resource cleanup.
* Explored the **Amazon Bedrock Playground** and learned how to work with Foundation Models for AI/ML experiments.
* Learned how to select a Foundation Model, provide Use Case information, create prompts, and run prompts using Amazon Bedrock.
* Learned how to create an **AWS Support Case** when access to an Anthropic Claude Model requires additional authorization.
* Practiced configuring **AWS Budgets** to monitor AWS costs and set up email notifications.
* Practiced creating a **Serverless Web Application using AWS Lambda** and the Lambda HTTP Blueprint.
* Learned the basic process of creating, testing, and deleting a Lambda Function.
* Practiced creating a **Managed Relational Database using Amazon RDS** and learned about **Aurora PostgreSQL Compatible**.
* Understood the importance of cleaning up AWS resources after completing practical exercises to avoid unnecessary resource usage and costs.
* Improved understanding of AWS cost monitoring, Budget management, and Free Tier Credit usage.
* Formed a team of **4 members** and prepared for future AWS project development.
